# Превью срезов кластеризации

Реальные сохранённые результаты извлечены из `SIGNALOGS. Материалы проекта/Signalogs_data/Сигналоги_FINAL.pptx`, слайд 64 «Сравнение кластеризации срезов по глубине со срезами модели».

Используются карты нижнего ряда в порядке колонок исходного слайда:

1. `slice-1.png`: `ppt/media/image168.png`.
2. `slice-2.png`: `ppt/media/image167.png`.
3. `slice-3.png`: `ppt/media/image169.png`.

Пиксели и цвета сохранены без изменений. Численные глубины и монотонный порядок погружения не установлены; подписи только «Срез 1 из 3» и т. п. Карта показывает классы, а не готовую однозначную фациальную интерпретацию.

Для MVP создан НОВЫЙ цикл длительностью 13 секунд из трёх исходных результатов. Старый видеофайл не найден. Самостоятельный пересчёт кластеризации и генерация промежуточных результатов не выполнялись. Веб-превью меняет изображения напрямую; видеофайл, видеокодек и внешние библиотеки не нужны. В автономный HTML встроены те же PNG. Подробности источника и SHA-256 — в `provenance.json`.

Управление: глобальная пауза над картой; в карточке СИГНАЛОГОВ — воспроизведение, ползунок выбора и увеличение текущего кадра. При выборе вручную показ приостанавливается. Скрытая вкладка и открытый увеличенный график останавливают автоматическое продвижение. При prefers-reduced-motion автоматический показ изначально выключен.
