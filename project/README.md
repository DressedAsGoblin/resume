# Исходники интерактивного резюме

Опубликованные страницы находятся в корне репозитория: `index.html` — адаптивная мобильная версия, `desktop.html` — карта для компьютера. Папка `project/` хранит материал для дальнейшего редактирования и не участвует в навигации сайта.

## Состав

- `mvp/` — редактируемая карта, оформление, логика навигации, данные проектов, карточки и их анимации. `mvp/assets/` содержит изображения, встроенные в сборку. `mvp/archive/first-draft-source.zip` — снимок самого раннего прототипа.
- `iterations/` — отдельные промежуточные HTML и эскиз. Это снимки этапов работы; они не заменяют текущие страницы в корне репозитория.
- `docs/` — согласованные формулировки, хронология проектов, план правок, источниковая карта и промпт эскиза. Тексты в HTML меняются только после редактирования соответствующих данных или шаблонов.
- `assets/signalogi/` — производные кадры для превью и восстановленный код сборки анимации с пояснением происхождения. Исходная презентация не опубликована.
- `tools/` — скрипты подготовки архива и обновления опубликованных страниц.

## Как внести изменения

1. Отредактируйте `project/mvp/world.js`, `world.css`, `projects-data.js`, `case-panel.*`, страницы отдельных чекпойнтов или их изображения.
2. Запустите `python project/tools/build_publish.py` из любого каталога. Скрипт пересоберёт `project/mvp/index.html`, автономную карту `project/Мир проектов — MVP.html` и заменит встроенную карту в `index.html` и `desktop.html`. Для этого нужны Python 3 и только стандартная библиотека.
3. Откройте обе опубликованные страницы локально и проверьте мобильную и широкую компоновку, анимации и карточки.
4. Зафиксируйте и отправьте изменения в ветку `main`; GitHub Pages публикует страницы из корня репозитория.

Для правок **текста резюме** понадобится локальный исходный документ `Исходные материалы/Общие материалы/Портфолио Research/baseline_ru.md` и пакет Python `markdown`, поскольку `project/mvp/build_resume.py` читает этот документ. Текущий опубликованный текст резюме уже содержится в `index.html` и `desktop.html`; пересборка карты его сохраняет.

Не опубликованы исходные презентации, PDF, резюме и другие документы из папки `Исходные материалы/`, а также сырой экспорт облачного чата и исходные изображения слайдов. Их содержимое остаётся в локальном рабочем каталоге. В документации архива встречаются ссылки на такие источники; это указатели, а не копии файлов.
