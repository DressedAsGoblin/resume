Корреляция пластов по ГИС и сейсмике

Дипломная работа Камиля Исхакова · совместное научное руководство

Метод Исхакова

  1. Синтетическая сейсмограмма

    По акустическому и плотностному каротажу моделируем отклик целевого интервала.

  2. Поиск по DTW

    Двигаем окно по ближайшей трассе. Меньшее расстояние DTW означает более похожую форму сигнала.

  3. Межскважинная корреляция

    Найденный интервал служит шаблоном для следующей трассы. У скважины Б сопоставляем результат с её синтетикой.

Проверка на сейсмическом профиле

На участке А–Б без разлома интервалы по DTW проследили сейсмический отражатель. В работе также рассмотрены участки с разломами.

Трассы на схеме демонстрационные.
