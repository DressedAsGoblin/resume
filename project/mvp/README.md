# Исходники карты проектов

`index.html` — редактируемая SVG-карта. Данные проектов находятся в `projects-data.js`, движение героя и навигация — в `world.js`, оформление — в `world.css`, карточки — в `case-panel.js` и `case-panel.css`. Сцены чекпойнтов хранятся в отдельных HTML-файлах этой папки; их список задан в `projects-data.js`. Карта содержит 11 проектов и завершающий пьедестал с контактами.

`build_world.py` формирует SVG-разметку карты в `index.html`. `build_single_file.py` собирает автономную карту `../Мир проектов — MVP.html` со встроенными ресурсами. В репозитории запускайте `python project/tools/build_publish.py`: он также обновит опубликованные `index.html` и `desktop.html` в корне.

`build_resume.py` отдельно собирает страницу резюме из локального исходного документа, который не опубликован. Для этого скрипта нужен пакет `markdown`. Сборка карты сохраняет опубликованный текст резюме и не требует этого документа.

`archive/first-draft-source.zip` — ранний снимок исходников. Файлы `app.js` и `style.css` относятся к нему и не используются текущей картой. Происхождение превью СИГНАЛОГОВ описано в `../assets/signalogi/depth-preview/`.
